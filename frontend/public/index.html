TECHNOLOGY — 技術スタック

本格的な技術基盤
Built with Modern Stack

FRONTEND

Next.js

TypeScript による型安全な UI 実装。画面遷移設計・レスポンシブ対応を含む、快適なユーザー体験を提供します。

BACKEND

Gin / Go

高速・軽量な Go 製フレームワーク。API 設計・ビジネスロジック・通知機能の実装を担当しています。

INFRA / DB

MySQL + Docker

MySQL によるスキーマ設計と Docker による環境構築・デプロイパイプラインで、安定した運用基盤を実現しています。
